# OfferPilot UI 风格探索

日期：2026-10-24。用途：供选择的概念图，未修改业务界面。生成方式：内置 image_gen；三个方向分别生成。

以现有找岗位页面与导航为基础，岗位均为合成示例。A 偏专业效率，B 偏温和精致，C 偏深色专注。图中细节为视觉提案，不代表功能已变更。

参考：[Linear 界面刷新](https://linear.app/now/behind-the-latest-design-refresh)、[Dia](https://www.diabrowser.com/)、[Perplexity Comet](https://www.perplexity.ai/comet)。参考信息层级和产品气质，不复制界面或品牌资产。

## A｜雾白石墨

预计文件：A-雾白石墨.png

~~~text
Use case: ui-mockup.
Asset type: high fidelity desktop web application visual proposal for OfferPilot, an existing Chinese AI job-search and interview-preparation workspace.
Primary request: create an exceptionally refined, premium minimal interface inspired by the craft and restraint of modern AI startup products. This is a realistic shippable app screen, not a landing page or a wireframe. Render a front-facing flat screenshot, wide 16:10 canvas about 1920x1200, razor-sharp typography, thoughtful spacing and alignment. No device frame or perspective.
Content and composition: left sidebar about 210px with small original geometric O symbol and exact brand "OfferPilot". Navigation in exact Chinese: "今日", "找岗位" (active), "岗位库", "我的申请", "面试准备", "我的资料", "复盘与 Offer". Bottom avatar with "个人工作空间". Thin top header: "工作空间 / 找岗位", small search shortcut and notification icon.
Main workspace: a poised heading "找到下一份值得投入的机会" with restrained subtitle "让 AI 整理岗位，把时间留给准备。". A beautifully composed natural-language search input containing "杭州或上海的 AI 应用实习，每周可到岗 3 天", with a compact primary "开始搜索" button. Under it subtle filter chips "AI 应用", "杭州 / 上海", "实习", "每周 3 天", and one discreet line "仅搜索公开岗位，不读取你的简历".
Below: results header "为你找到的机会", count "12 个岗位 · 3 个待核实", compact tabs "推荐" and "全部", sort "相关性". In the left content column, three carefully aligned job entries with ample whitespace, small original monogram company marks, company + title, condition snippets, two or three understated skill tags, bookmark icon and source/status microcopy. Synthetic entries: "云杉智能" / "AI 应用开发实习生" / "杭州 · 200–300 元/天" / "Python" "API" "RAG" / "已读取正文"; "栖光科技" / "前端开发实习生" / "上海 · 薪资待核实" / "Vue 3" "TypeScript"; "北岸科技" / "Python 后端实习生" / "杭州 · 每周 3 天" / "Python" "PostgreSQL".
Right lower column: a refined selected-job detail panel for the first item with compact title "岗位速览", structured sections "岗位要求", "信息核验", "准备建议", readable short lines, a gentle amber note "每周到岗天数待核实", understated "查看原始来源 ↗", and one primary action "加入申请". Do not show a match percentage, offer probability, large charts, fake metrics or decorative dashboard widgets.
Typography: immaculate Chinese typesetting, legible sans body, elegant scale, semibold headings, subdued metadata that remains readable. Avoid excessive pill badges, nested cards, thick outlines, huge headings, blue enterprise-admin boilerplate, shiny gradients, glassmorphism, 3D blobs, illustrations, neon glow, or large empty marketing hero space. Use simple consistent line icons. All text and controls must be crisp and plausible. Add tiny discreet footer "界面概念 · 合成岗位".
Style direction A — GRAPHITE / Precision light. Take conceptual inspiration from Linear's calm hierarchy, muted navigation, meticulously aligned rows, and concentrated interaction design, without copying logos or exact layouts. Palette: canvas #FAFAFB, side navigation #F3F4F6, white content, graphite #202124 text, cool grey hairlines, a single understated periwinkle #6466D9 accent. Dense but unhurried professional tool. Small 8px radii, extremely subtle borders and almost no shadow. Results should feel like curated editorial list rows, not chunky cards. Selected first row uses an almost invisible lavender-grey tint. Primary search button graphite; small selected navigation/accent and one detail-panel action use periwinkle. Strong horizontal rhythm, generous margins, beautifully calibrated type contrast. A tiny label "A / GRAPHITE" can sit at the far right of the footer.
~~~
